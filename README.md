# Oil Production Analysis

## Project Overview
Data Analysis and Machine Learning project to predict Oil Production using RandomForest Regressor.

## Tools Used
- Python
- Pandas, NumPy, Matplotlib, Seaborn
- Scikit-learn - RandomForest
- Google Colab

## Key Analysis
- **EDA**: Data cleaning and correlation analysis
- **Visualization**: Correlation Heatmap & Feature Importance  
- **Model**: RandomForest with R2 Score evaluation

## Files in this Repo
- `Untitled3.ipynb - Colab.pdf` - Full analysis and results
- `correlation_heatmap.png` - Features correlation
- `feature_importance.png` - Most important features
